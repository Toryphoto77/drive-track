# DriveTrack 外壳 v9 说明

配套 PCB：**DriveTrack-PCB-V5 叠板**（52.00 × 70.00 × 1.60 mm）。  
状态：**检查用原型**，不是量产放行。首件必须试装后再决定是否外用。

本外壳在机械方案上取代扁形 v8。v8 仍可在较早的检查包里对照。

## 外形（已按叠板实板锁定）

| 项目 | 尺寸 (mm) |
| --- | --- |
| 盒体（不含密封翻边） | 58.20 × 76.10 × 26.50 |
| 含密封翻边（总包围盒） | 74.20 × 92.10 × 26.50 |
| 顶盖字凸起后总高 | 约 26.95（字高凸起约 0.45） |
| 内腔平面 | 53.20 × 70.60 |
| 内腔净高 | 22.30（底板顶面 z=2.20 到盖内顶 z=24.50） |
| 密封分型面 | z=20.00 |
| 相对 v8 盒体 | v8 为 107.00 × 66.10 × 20.00；本版平面更小、高度更高 |

坐标系：与 PCB 一致。盒内 PCB 原点（板左上 / 指示灯 / 迎风 FRONT 角）落在外壳 (3.10, 3.10)。+Y 指向 USB 墙。

## 高度叠层

底板 2.20 + 电芯下泡棉 1.00 + 电芯 10.00 + 绝缘 0.40 + 板 1.60 + 按 JST-PH 目录值约 8.00 的顶部空间 + 盖内净空 + 2.00 厚盖板，锁定外高 26.50 mm。陶瓷天线按约 4 mm 估计，低于 JST，不决定总高。这些厚度除板厚外都是假设值，须用实物核对。

板坐在 z=13.60–15.20。因此 USB 开孔中心在 **z=14.40**，比 v8 的 z=5.00 高很多，试装时不要沿用旧开孔高度。

## 材料与射频

- 原型材料：**ASA**。
- 陶瓷天线正上方盖板厚度 **2.00 mm**。
- 天线区域必须射频透明：不要金属嵌件、不要碳纤维、不要含金属漆或金属镀层覆盖 GNSS 区域。
- 2.4 GHz FPC（34 × 12 mm，另加少量余量）做在盖内侧凹槽里，已避开陶瓷天线投影。IPEX 线槽同样避开该区域。

## 防水规则（相对前代不得回退）

- 盒盖四颗 M3 螺钉走翻边四角的实心柱，**在密封绳回路外侧**。螺钉孔不进入密封腔。
- PCB 支柱从下方看是盲孔：底板在 z=0 处闭合，自攻导孔从 z=1.00 向上，不打穿底板，也不进入电芯软包。
- 密封：Ø2.0 硅胶绳，底壳分型面开 2.60 × 1.50 mm 槽，盖内侧有 1.60 × 1.20 mm 凸台与之配合。
- USB 开孔有独立密封凹台，需另配 USB 密封件（例如硅胶塞或密封套）。本模型只预留凹台，不包含密封件本体。
- 透气孔在 −X 墙、靠近 BMP390，有膜片凹台；需另配透气膜，模型不包含膜片本体。
- 指示灯窗口是 **0.80 mm 厚的薄壁膜**，不是穿孔。打印后可视需要再贴茶色/烟色片，但不要把窗口打穿。
- **侧壁没有任何电源按键孔。**

## 减振

- 电芯仓底部有 1 mm 深的泡棉槽，长边有低挡边。电芯四周在空间允许处按 0.80 mm 级间隙预留包覆；−X / FRONT 受板边限制，实际包覆会略窄。
- 电芯顶面与板底之间请加绝缘片或薄泡棉（设计按 0.40 mm 预留），不要让软包直接顶在板底元器件或焊点上。
- 右侧余条地板有三处 8 × 8 × 1.5 mm 泡棉槽。FRONT 板边有 1.80 mm 深的托台，补上该角没有螺钉的承托。
- 请用闭孔泡沫或电池专用泡棉，不要把电芯直接硬顶在硬塑料上。

## 顶盖文字

- 只使用英文。字体为包装内 `fonts/InterTight-700.ttf`（Inter Tight Bold）。
- “DriveTrack” 大写字身目标高度 7.00 mm。实测外接矩形约 50.47 × 7.50 mm，多出的高度来自部分字母的字身延伸，不是把字身改成 7.5 mm。
- “FRONT” 与箭头在指示灯窗口东侧，箭头指向 −Y（迎风端）。
- 文字方向：俯视时把 FRONT / 指示灯端放在画面上方即可正向阅读。实现上对字母做了沿 X 轴的镜像（只翻上下，不左右对调），避免再出现整行倒置或反字。`previews/lid-lettering-check.png` 是按这个方向单独描出来的校对图。
- 盖上没有中文。

## 打印

只打印这两个文件：

- `base-v9.stl` — 底壳
- `lid-v9.stl` — 盒盖

`assembled-v9-DO-NOT-PRINT.stl` **只供预览，不要送去打印。** 它是底壳与盒盖的网格拼接，分型面处有重叠，不是可打印实体。

建议（首件，供参考，需按打印机和材料再调）：

- 材料：ASA，热室或足够封闭的腔体，注意翘曲。
- 层高 0.16–0.20 mm；密封槽、USB 口、灯窗薄壁处适当减小层高或增加墙线。
- 底壳开口朝上或按打印机习惯摆放，注意 USB 开孔（位置比扁形版高）和密封槽的表面质量。
- 盒盖字面朝上，便于字凸起和灯窗薄壁成形。切片时把 FRONT 端放在画面上方，确认 “DriveTrack” 正向可读。
- 0.80 mm 灯窗很薄，切片时检查是否被当成过薄特征丢掉。
- 打印后清理导孔，先用 M2 / M3 螺钉在废料上试攻，再装到成品上。

重建模型：CadQuery 2.8 + trimesh + manifold3d + shapely + fontTools + matplotlib。不要把虚拟环境打进工程包。在已安装依赖的环境中运行：

```
python enclosure_v9.py
python verify_v9.py
python render_previews_v9.py
```

## 几何检查

`verify_v9.py` 已对导出的 STL 做过检查，日志见 `verify-v9.log`。底壳和盒盖均为封闭体积；预览用组装体因拼接方式不是封闭体，这是预期现象。检查项目包括：安装柱不打穿底板、安装柱不进入电芯投影、灯窗不是穿孔、USB / 透气孔存在、侧壁无按键孔、螺钉在密封绳外侧且不进入内腔、FPC / IPEX 不压陶瓷天线投影、USB 开孔低于密封翻边、总高在 24–28 mm 规划带内。本次结果为全部通过。

## 开放事项（打印或外用前必须核对）

- USB-C 中置连接器与 12.40 × 6.80 开孔、**新的板中面高度 z=14.40** 的实配，包括插头护套。
- 实际 104060 电芯公差、极耳方向、保护板厚度，以及折到 J3 的线长。
- 陶瓷天线实际高度（设计按约 4 mm 一类贴片估计，须对实物）。

- 透气膜、USB 密封件、指示灯遮光片的选型和粘贴。
- ASA 首件的密封槽尺寸与 Ø2.0 硅胶绳的松紧。
