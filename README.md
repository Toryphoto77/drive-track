# 驰迹 DriveTrack

> 把每一次驾驶，记录成能被复盘的数据。

驰迹是一款为「认真开车的人」做的驾驶记录 App：汽车、摩托、卡丁车三种模式，一键开始记录。轨迹、车速、G 值、姿态、定位精度全程留存，赛道日还能自动计时、逐圈复盘。

黑色 HUD 界面，没有导航式的杂乱信息：开的时候只看该看的，停下来再慢慢看数据。

## 我们想做的事

市面上的行车记录大多停在「画一条线」这一步：轨迹有了，但看不出哪一脚刹车早了、哪一个弯出得慢了。驰迹想把它往前推一步——同一份数据，既能在赛道上告诉你这一圈差在哪，也能在日常通勤后告诉你这段路开得稳不稳。

三条原则贯穿整个产品：

- **记录不该打扰驾驶**：记录界面只有必要的数字，语音播报代替盯屏，倒计时带强震反馈。
- **数据留在你手里**：默认只存本机，云端上传、公开行程都是手动操作，不做自动同步。
- **结论要看得懂**：不给一串看不懂的曲线，给圈速、Delta、分段着色和一句能执行的提示。

## 核心功能

### 三种模式

- **汽车 / 摩托**：街道记录，超速与 GPS 丢失语音提醒，出行天气播报。
- **卡丁车**：为赛道日准备的精简计时界面——大号圈速、圈号、左右两道 Delta 色条，扫一眼就知道快慢。
- 历史里的骑行行程仍可正常打开与查看。

### 赛道计时

- 进入赛道或卡丁前会校验外接定位是否就绪（是否连接、是否只输出二进制、是否已有定位、采样率是否达到 5Hz），不满足时直接说明原因并跳到设备页，避免记出一堆无效数据。
- 过线瞬间三重反馈：语音播报圈速、短震动、全屏闪一帧（绿色代表个人最佳，红色代表慢于参照）。
- 大字当前圈 + 分段着色 + 官方分段点 + 带符号 Delta，默认以本场最佳圈为参照。
- 赛道库收录 F1、中国系列与经典赛道共 78 条，几何逐条核对，长度对照 FIA 官方数据。
- 0–100 / 100–0 性能测试；驾驶习惯评分，扣分项逐条透明可见。

### 赛后复盘

- 数据页为车队遥测风格：速度、海拔、弯道曲线共用一条时间轴联动。
- 完赛汇总：圈速折线配逐圈数据（最佳圈高亮），给出中位圈、平均圈、圈速标准差与一致性，一眼看出这场的节奏是稳还是崩。
- 曲线 + 着色线路，不依赖视频也能复盘。
- 行程可导出、可分享；赛道包支持官方更新与本地编辑，官方更新不会覆盖你的改动。

### 外接设备

- 单入口扫描外接定位：DEXIAN D1、RaceBox、Dragy、Qstarz 等，通用 NMEA 兼容（私有协议以实测为准）。
- 自研 GPS + IMU 硬件方案推进中（ESP32-S3 + NEO-M9N + BMI088 + 气压计，车顶安装）。

### 云端（可选）

- 不登录也能用完整体验；登录后行程只在你点上传时才上传。
- 行程与公开资料可设为公开，默认仅本人可见。

## 下载

最新版见 [Releases](https://github.com/Toryphoto77/drive-track/releases/latest)（当前 v1.6.3）。按手机架构选一个，大多数手机用 arm64-v8a：

| 安装包 | 适用机型 |
| --- | --- |
| `DriveTrack-v*-release-arm64-v8a.apk` | 绝大多数安卓手机 |
| `DriveTrack-v*-release-armeabi-v7a.apk` | 老款 32 位手机 |
| `DriveTrack-v*-release-x86_64.apk` | x86 平板 / 模拟器 |

直接覆盖安装即可升级，不要卸载重装（本机行程存在本地，卸载会丢）。

App 内「关于 → 检查更新」会自动匹配当前架构的安装包，并对下载文件做 SHA-256 校验。

## 已知限制

- 传感器零偏校准只存内存，重启 App 需重新校零。
- 外接定位协议以通用 NMEA 为主，私有协议设备以实测为准。
- 路网来自公开 Overpass 服务，服务繁忙或网络不通时会提示失败原因，可手动重拉，上次成功的数据按位置缓存。
- 个人页填写的邮箱只存本机，不用于登录。
