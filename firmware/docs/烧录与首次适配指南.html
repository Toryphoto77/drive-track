2第一次串口烧录

  1. 把 USB-C 插到主板，另一端插电脑。打开「设备管理器 → 端口 (COM 和 LPT)」，应出现一个新的 USB 串行设备，例如 COM5。记下这个编号。
  2. 如果没出现串口：换一根确定能传数据的线；拔掉再插；仍然没有就按住 BOOT（IO0）再插 USB，进入下载模式后松手。
  3. 解压固件包，在 tools 目录打开 PowerShell，执行： 
    powershell -ExecutionPolicy Bypass -File .\flash_firmware.ps1 -Port COM5
    COM5 换成你上一步看到的端口。
  4. 看到 Hash of data verified. 和 Hard resetting via RTS pin... 就是烧录成功。整片新板第一次烧录可以加 -Erase，会先清空再写。
  5. 设备自动重启，状态灯 IO7 每 2 秒短闪一次。

不想用脚本？等价的手动命令

python -m esptool -p COM5 -b 460800 --before default_reset --after hard_reset write_flash ^
  --flash_mode dio --flash_freq 80m --flash_size 16MB ^
  0x0     bin\bootloader.bin ^
  0x8000  bin\partition-table.bin ^
  0xf000  bin\ota_data_initial.bin ^
  0x20000 bin\drivetrack-box-0.3.0.bin
ESP32-S3 的 bootloader 偏移是 0x0；只有老款 ESP32 才是 0x1000，别照抄旧教程。
烧录中如果报 Failed to connect 或 MD5 of file does not match：先确认串口没被串口助手占用，再把 -Baud 降到 115200 重试。

3烧完之后怎么验证

串口日志

python -m serial.tools.miniterm COM5 115200

正常应依次看到：

DriveTrack V4.6 fw=0.3.0 build=3
GNSS 波特率探测命中 38400 bps
BMI088 已启动 20 Hz
WiFi 热点已启动 SSID=DriveTrack-XXXX
BLE 已启动，等待 App 连接

WiFi 与 HTTP

  1. 手机 WiFi 列表里连 DriveTrack-XXXX，密码 drivetrack123。
  2. 浏览器打开 http://192.168.4.1/api/info，应返回： 
    {"model":"DT-BOX-1","board":"DriveTrack V4.6","fw":"0.3.0","build":3,
 "battMv":4020,"battery":90,"freeHeap":142336,"uptimeMs":35000}
  3. battery 是 App 上显示的电量百分比；battMv 与万用表测的电池电压相差应在 ±100 mV 内。
  4. http://192.168.4.1/api/status 应返回 recording / fix / sats / caps，App 的硬件卡就靠它刷新。

蓝牙

手机蓝牙列表里能看到同名 DriveTrack-XXXX。不需要在系统设置里配对，直接回 App 里连接。

4App 首次适配（按这个顺序）

  1. 安装新版 DriveTrack 1.7.6+75（本次更新包含底栏跟手与硬件适配）。
  2. 首次启动按引导授权：定位、通知、蓝牙。蓝牙权限拒绝会导致搜不到设备。
  3. 打开「设备中心 → 扫描设备」，列表里会出现 DriveTrack-XXXX，点它连接。
    连接成功后，回到首页，外接 GPS 状态药丸会变成绿色并显示设备名。定位数据通过蓝牙 NMEA 实时进来。
  4. 要看电量 / 固件版本 / 关机这些硬件信息，需要手机连上设备热点：
    1. 手机 WiFi 连 DriveTrack-XXXX；
    2. 回到 App「设备中心」，硬件卡会自动刷新电量和版本。
  5. 如果要升级固件：保持连在设备热点上，进入「设备中心 → 固件升级」，App 会检测版本、下载镜像并通过 WiFi 写入，设备自动重启，全程不用插线。
Android 连上设备热点后会提示「此 WLAN 无法访问互联网」，选择保持连接。否则系统会自动切回移动网络，App 就访问不到 192.168.4.1。
首次适配完成的标志：首页 GPS 药丸绿色显示设备名；骑行时能看到实时速度与轨迹；设备中心硬件卡显示电量、固件 0.3.0、定位卫星数。

5之后怎么升级固件

不用再插线。发布新固件后，App 的固件升级页会提示新版本：

  1. 手机连设备热点。
  2. 设备中心 → 固件升级 → 检查更新。
  3. 下载并升级，等待设备重启（约 10 秒）。

升级写入的是另一块 4 MB 分区，校验 SHA-256 后才切换启动分区；新固件跑满 10 秒未崩溃才取消回滚，失败会留在旧固件，不会变砖。

6常见问题

现象处理
设备管理器没有 COM 口换数据线；按住 BOOT 再插 USB；换一个 USB 口（避免前置面板 / Hub）
烧录卡在 Connecting...按住 BOOT（IO0），点一下复位或重新插 USB，看到 Connecting 后松手
WiFi 里搜不到热点看串口日志是否有 WiFi 启动报错；确认天线接好；断电重启
连上热点但打不开 192.168.4.1安卓提示无互联网时选“保持连接”；关闭手机流量助手 / 智能切换网络
App 搜不到蓝牙设备检查系统蓝牙已开、App 蓝牙权限已给；设备串口日志应有 BLE 已启动
定位一直不 fixGNSS 天线放到窗边或室外，首次冷启动搜星可能要 1~3 分钟

App 电量显示 “—”确认连的是设备热点、固件 0.3.0；用浏览器打开 /api/status 看是否有 battery 字段
