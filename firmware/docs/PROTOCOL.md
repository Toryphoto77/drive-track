# 通信协议（PROTOCOL）

> 本固件对手机只做一件事：把 GNSS 的 NMEA 文本通过 BLE 串口推给 App。
> App 侧解析代码见 `lib/blediy_gps.dart`，连接与订阅见 `lib/device_center.dart`。

## 1. BLE 服务（Nordic UART Service）

| 角色 | UUID | 属性 |
| --- | --- | --- |
| 服务 | `6e400001-b5a3-f393-e0a9-e50e24dcca9e` | — |
| TX（设备 → 手机） | `6e400003-b5a3-f393-e0a9-e50e24dcca9e` | Notify |
| RX（手机 → 设备） | `6e400002-b5a3-f393-e0a9-e50e24dcca9e` | Write / Write Without Response |

- 广播名：`DriveTrack-GPS`（可在 `config.h` 改）。
- 广播包含上面的服务 UUID，App 的服务过滤扫描可以直接命中；
  同时也会出现在无过滤扫描列表里。
- 连接参数由手机决定；设备按 `MTU - 3` 自动分片，不假设固定包长。

### 带宽

| 配置 | 每周期字节（GGA+RMC+GSA） | 10 Hz | 25 Hz |
| --- | --- | --- | --- |
| MTU 23（每包 20 B） | ~220 B | ~110 包/s | ~275 包/s（不够） |
| MTU 247（每包 244 B） | ~220 B | ~1 包/周期 | ~1 包/周期 |

因此 App 侧在服务发现后主动 `requestMtu(247)`；固件检测到协商结果后
按新 MTU 分片。若手机未协商成功，10 Hz 仍可用，25 Hz 会丢包。

## 2. 数据格式

标准 **NMEA 0183**，ASCII，每行以 `\r\n` 结尾。固件只转发以下语句：

| 语句 | 内容 | App 用途 |
| --- | --- | --- |
| `GGA` | 经纬度、定位质量、卫星数、HDOP、海拔 | 位置、卫星数、hz 计次 |
| `RMC` | 经纬度、速度（节）、航向、UTC | 位置、速度、航向、时间 |
| `GSA` | 定位模式（2D/3D）、参与解算卫星数 | 模式、星数兜底 |

关闭的语句：`VTG`（RMC 已带速度）、`GSV`、`GLL`（省带宽）。

示例：

```
$GNGGA,072345.00,3110.12345,N,12122.54321,E,1,12,0.8,12.3,M,0.0,M,,*6A
$GNRMC,072345.00,A,3110.12345,N,12122.54321,E,0.05,45.2,191126,,,A*7B
$GNGSA,A,3,12,15,18,24,25,29,,,,,,1.2,0.8,0.9*2D
```

> 坐标基准为 **WGS-84**。App 的赛道包同样来自 OSM/WGS-84，不需要
> GCJ-02 纠偏；这与高德底图不同，不要混用。

## 3. 定位与频率

- 输出频率：默认 **10 Hz**，可在 `config.h` 改 `GNSS_RATE_HZ` 为 25。
- 固件启动时通过 UBX-CFG-RATE 把模块设为对应频率，并持久化到模块。
- App 的 Hz 统计按 GGA 计；连续 5 秒没有新定位会回落手机 GPS。
- App 的赛道模式硬件门槛：已连接、能解析、采样率 ≥ 5 Hz。

## 4. 控制命令（可选）

手机向 RX 特征写入 ASCII 命令，设备不回复 ACK（除 `STATUS?`）：

| 命令 | 作用 |
| --- | --- |
| `RATE=10` | 切换 GNSS 输出频率（1–25） |
| `STATUS?` | 通过 TX 返回一条状态语句 |
| `REBOOT` | 重启设备 |

`STATUS?` 返回示例：

```
$PDRT,STATUS,rate=10,fix=1,lines=1234,mtu=247,drops=0*5C
```

## 5. 自定义语句（预留）

IMU 数据推送（`$PDIMU,...`）**尚未实现**：当前 App 不解析外部 IMU，
推了只会占用 BLE 带宽。等 App 增加外部 IMU 输入后再补协议。

## 6. 与 App 对接要点

1. App 扫描到设备后按 NUS 订阅 TX 特征。
2. 收到的字节流按 `\n` 切行，交给 `BleDiyGpsFeed`。
3. `GGA` 提供位置、卫星数、HDOP、海拔；`RMC` 提供速度与航向。
4. 断线后 App 立即回落手机 GPS；重连会重新订阅。
5. 不要修改 NUS UUID，除非同时改 App 的 `blediy_gps.dart`。
